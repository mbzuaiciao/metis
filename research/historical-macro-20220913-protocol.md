# Frozen protocol: historical context and hypothesis generation

Frozen before inference on 2026-11-03 (America/Los_Angeles). This is a new one-case study, not a resumption of the stopped v0.3 narrative ablation. Base revision: `6b17068b446f9a2896184068aa8485a093642879`. PR #3 was already merged at this revision; no PR/UI changes.

Question: does supplied historical macro context add useful economic mechanisms beyond what portfolio exposures, observed moves and deterministic P&L already support?

- One episode, existing twelve synthetic positions, unchanged engine. See the adjacent inputs JSON for source values, clocks, conventions and explicitly illustrative mappings. Omit unavailable credit spread changes; do not interpret engine zero placeholders as observations.
- A then B, one isolated request each, maximum **two live requests**, no retries, repair calls, replacements, additional cases or LLM judge. Failure or unavailable inference is a result to report; no demo substitution. No shared conversation history.
- Use configured Meta `muse-spark-1.3`, `https://api.meta.ai/v1/chat/completions`, temperature 0.2, completion budget 8,000 including reasoning, `reasoning_effort=low`, timeout 60s, strict research-only JSON schema. No seed configured; hosted weights/provider revision unavailable.
- Both requests use identical system instructions, question, schema, portfolio, observations, assumptions and engine results. A omits date, event title, source URLs/news, CPI and narratives. B adds only `context.macro_context`, with the dated facts and their URLs. Source IDs and neutral observation labels remain in A for auditing but no source catalog. The filename/condition label is not sent to the model. The B information cutoff is end September 13, 2022; no later policy outcome.
- Return two or three hypotheses, each with name, economic mechanism, market connection, portfolio implications, uncertainty/competing explanation. They may overlap. No probabilities, trading instructions, causal identification or requests for private reasoning.
- Preserve exact outgoing JSON (excluding authorization headers), exact response body, parsed content, hashes, usage, finish reason, status and UTC timestamps/latency in ignored `research/runs/`, directory 0700/files 0600. Commit reviewed paraphrases and non-sensitive telemetry, never raw responses. Do not rerun a completed study by default; offline preparation is the default command.

Manual qualitative evaluation, specified before outputs: historical specificity, economic mechanism, cross-asset coherence across available evidence, portfolio relevance, and uncertainty. Check all stated numbers/signs against the engine and source inputs. Evaluate whether B links facts to transmission channels and exposures, qualifies competing explanations and notices evidence limitations. Repeating CPI/news, adding dates or being longer is not improvement. A may infer the same channels without news; pretrained event recognition is possible even without a date. Do not penalize missing credit explanation when credit data is absent.

Decision rule: report observed incremental substance, no detectable incremental substance, mixed results, or unavailable comparison. Even a positive sample supports only this sampled pair, not reliability, causal effects, general superiority or integrating retrieval. Stop after the bounded pair and documentation/local commit; do not push or merge.
